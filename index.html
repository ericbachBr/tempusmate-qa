Regras de domínio confirmadas

R-01

Profile ID is authoritative

When profileId/clientId exists, Profile identity wins over editable text.

R-02

Manual name is not Profile identity

Exact normalized name matching may be used only for approved eligibility/read-only legacy compatibility.

R-03

One client per Employee Invoice

Protected employee rows must not be silently mixed across client identities.

R-04

Historical snapshot wins

Imported/existing rows preserve rate, overtime and rules; current client defaults seed new rows only.

R-05

Break maximizes employee pay

Break minutes are deducted from the lowest active multiplier bucket first.

R-06

Decimal internally, formatted visually

Financial math keeps decimal hours; UI uses hours/minutes formatting.

R-07

Duplicate protection is per Invoice

The same historical Shift may appear in multiple Invoices, but not twice in the same one.
